# 验收与当前边界

## 自动化验证

`npm test` 检查：北京时间和重复规则、过去时间拒绝、确认幂等、密码摘要与密钥加密、登录和来源校验、配置缺失、手机版本 ACK、关闭闹钟的取消同步状态、公众号异步结果、网络中断与后台重启、迟到超过五分钟、最多三次重试、旧版本取消、订阅 SSE 中断，以及 OAuth state 校验。

`npm run test:e2e` 用独立后台数据库与本机 Edge，实际执行首次登录、手动建立、确认、修改、取消、添加联系人、两个 OpenAI 入口、登录记忆，并检查390px手机和1440px电脑布局。另用模拟麦克风和识别回复验证“问候 → 静音自动提交 → 复述 → 语音确认 → 实际数据库只保存一次”。截图保存到 `test-results`。没有使用真实模型凭据或微信账号发送。

## 仍需真实设备和凭据

- iPhone 工程在 Xcode 编译、免费签名、真机一分钟闹钟；锁屏、静音、专注模式和签名到期后的行为。
- 百炼或其他厂商真实 Key 的识别、理解、朗读；无效 Key、额度不足、网络错误。麦克风开始前播放问候，结束后才收音，最多60秒，静音2秒提交，首轮无声10秒停止。
- OpenAI 官方本机订阅账户的资格、授权返回、可见模型和实际推理。OAuth 流程已实现，但没有用你的账户完成授权。
- pushplus 本人/好友 token、secretKey 和安全 IP 的真实发送与结果查询。首个发送测试只给本人，随后由你确认建立亲友提醒。
- Edge 的真实推送订阅、关闭标签页后通知、Windows 睡眠/断网和通知权限；结果成功不保证设备一定展示。
- Docker、域名、HTTPS、每日备份与异地恢复。服务器没有运行时不发送通知。

## 已知首版范围

- 原生系统闹钟只支持 iOS 26+，安卓可使用网页、公众号提醒，没有安卓系统闹钟实现。
- Windows 网页可以安装，但无后台系统精确闹钟。通知依赖浏览器推送服务和设备状态。
- 全部新增和修改需要联网。手机已成功登记的闹钟由系统执行，后台修改/取消需要前台同步。
- 提醒文字理解来自可配置厂商，后台校验字段、时间、接收人和渠道，确认前不会创建真实提醒。
- 重名或含糊时间主要依赖模型追问；模型仍可能误解，必须在确认卡片核对具体日期和接收人。未接入按节假日调整的工作日。
- 原生设置尝试读取真实签名到期时间，支持本机更新通知；读取失败时显示未知并提示第6天更新，此能力仍需真机验证。
- 发送结果未知保留记录并停止自动重发。首版没有自动将未知请求重新发送给亲友的按钮。
- 服务与数据库按单实例设计。没有公开注册、共享账号、多租户和上架功能。
